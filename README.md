# Hestia

Установщик и панель управления домашней сетью. Цель: человек ставит одно приложение — и дальше
оно само разворачивает себя на его серверах, находит существующую инфраструктуру, показывает её
и (позже) ставит/подключает сервисы плагинами: DNS, CA, Samba, Gitea, репозитории и т.д.

Статус: проектирование. Кода нет.

Документы:
- docs/plan/00-vision.md        — видение и принципы
- docs/plan/01-architecture.md  — компоненты, транспорт, данные, плагины
- docs/plan/02-stage-1.md       — первый этап (MVP): подключение → самоустановка → инвентаризация, карта, AdGuard
- docs/plan/03-roadmap.md       — дальнейшие этапы и плагины
- docs/plan/99-decisions.md     — принятые решения и открытые вопросы

Стек: Go + Svelte 5 / Tailwind 4 / DaisyUI 5 (как Rhea и Iris).
